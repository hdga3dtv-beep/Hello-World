# Correcciones pendientes (sin aplicar)

Propuestas por la verificación cruzada, un archivo por lote.
Todavía no se aplicaron a `datos/`; se aplican solo las que acepte el verificador escéptico.
Cada archivo es una lista de correcciones con `id`, `field`, `new_value`, `problem`, `evidence` y `confidence`.
Los componentes nuevos propuestos por los críticos de completitud están en `../complementos/`.
